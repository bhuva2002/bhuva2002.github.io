# Portfolio Website - Yash Bhuva

A modern, professional portfolio website showcasing my experience, projects, and skills as a Software Developer at IBM India.

## 🌟 Features

- **Modern Design**: Clean, minimalist design inspired by professional developer portfolios
- **Interactive Cursor**: Large spotlight effect that follows your mouse for an engaging user experience
- **Smooth Animations**: Scroll-based animations and hover effects throughout the site
- **Responsive Layout**: Fully responsive design that works seamlessly on desktop, tablet, and mobile devices
- **Dark Theme**: Professional dark navy color scheme with teal accents
- **Accessibility**: Built with accessibility in mind, including skip links and proper ARIA labels

## 🎨 Design Highlights

### Color Palette
- **Primary Background**: Dark Navy (#0a192f)
- **Accent Color**: Teal/Green (#64ffda)
- **Text Colors**: Various shades of slate for hierarchy
- **Shadows**: Subtle navy shadows for depth

### Interactive Elements
- **Spotlight Cursor**: 800px circular gradient that follows mouse movement
- **Hover Effects**: Experience and project items highlight on hover with subtle animations
- **Smooth Scrolling**: Navigation links smoothly scroll to sections
- **Active States**: Navigation automatically updates based on scroll position

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone or download this repository
2. Navigate to the `site` folder
3. Open `index.html` in your web browser

Or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js with http-server
npx http-server
```

Then visit `http://localhost:8000` in your browser.

## 📊 Performance

## 🎨 Customization

### Changing Colors
Edit the CSS custom properties in `styles.css`:
```css
:root {
  --dark-navy: #0a192f;
  --green: #64ffda;
  /* ... other colors */
}
```
